Technical Specification

Architecture & Non-Negotiable Engineering Rules

Directly adhering to the repository specification in CLAUDE.md.

Rule 1: Ledger-First Money Rule

The LLM must NEVER generate a rupee amount. Every figure shown to the worker originates strictly from packages/shared/lib/src/ledger.dart.

Rule 2: Citation Discipline

Every scheme answer must cite its official source (PIB, Gazette). Low-confidence RAG returns helpline fallback 1800-425-1200.

Rule 3: Draft Disclaimer

Every draft (grievance, agreement, demand notice) must include the exact statutory disclaimer advising consultation with an advocate or helpline.

Rule 4: Escalation Triggers

Mentions of assault, threats, or severe abuse abort standard procedural grievance flows and immediately surface Police 112 & Labour 1800-425-1200.

Rule 5: Client API Key Protection

The Sarvam AI API key is isolated in Firebase Cloud Functions environment configuration. The Flutter and Web clients never store private keys.

Rule 6: e-Shram API Limitation

No public e-Shram API exists. The system acts as a step-by-step guidance companion; no scraping or pretending to query government databases.
